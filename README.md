# Excel Sales & Customer Analytics Dashboard

## 📊 Project Overview

This project is an interactive Sales & Customer Analytics Dashboard created using Microsoft Excel.

The dashboard helps analyze sales performance, customer activity, product performance, and key business metrics.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- VLOOKUP
- INDEX & MATCH
- Excel Functions
- KPI Analysis
- Dashboard Design

## 📈 Dashboard Features

- Total Sales
- Sales Performance Analysis
- Customer Analysis
- Product Performance
- Interactive Charts
- KPI Cards
- Pivot Table Analysis
- Data Filtering

## 🎯 Purpose

The purpose of this project is to transform raw sales data into meaningful business insights through Excel-based data analysis and visualization.
